# 实验结果（2026-10-28）

本机 RTX 4060 Laptop，`torch 2.11.0+cu128`，seed 42。指标是反归一化后有效格上的 MAE / RMSE，单位为每小时上车量。MAPE 只在真实流量大于 0 的格子上计算，分母为该流量；下表 MAPE 来自对已有 checkpoint 的重算，没有重新训练。权重、日志和原始数据在本机，按 `.gitignore` 不入库。逐步记录见 [../notes/progress.md](../notes/progress.md)。

## 协议

- 输入为过去 6 小时，预测下一小时。验证集和测试集各 1440 小时。
- 源城教师（纽约、芝加哥）只在 5898 个训练窗口上训练。验证集用于早停，测试集只评估一次。这与 CrossTReS 把源城 train+val+test 拼进预训练不同。
- 华盛顿只用训练段最后 72 小时（3 天）。验证集和测试集仍各 1440 小时。
- 模型是带 BatchNorm 的 CrossTReS ST-Net。损失为有效格平方误差，先对 batch 取平均，再对格子求和。batch 8，学习率 0.001，权重衰减 5e-5，最多 50 个 epoch，验证 RMSE 连续 5 个 epoch 不升则停。
- Group 2 的教师直接吃华盛顿归一化窗口，不做区域匹配。蒸馏项与任务损失使用同一归约，λ = 1。学生随机初始化。
- G1-C 把源城权重复制到华盛顿后全部解冻，只有任务损失，没有蒸馏。

## 微调加蒸馏（种子 42，λ = 1）

学生先复制源城教师权重（去掉源城 `spatial_mask`），教师另存一份并冻结，损失仍是 `L_task + 1.0 * L_kd`。协议与上面的华盛顿 3 天设定相同：batch 8，学习率 0.001，权重衰减 5e-5，早停 patience 5。MAPE 只在反归一化后真实流量大于 0 的格子上计算，分母就是该流量。RMSE 和 MAE 仍覆盖全部有效格。上面主表的 MAPE 已按同一规则重算。

| 实验 | 设定 | 最佳 epoch | split | MAE | RMSE | MAPE |
|---|---|---|---|---|---|---|
| G2-NY2DC-init | 纽约权重复制到学生后再蒸馏 | 5 | val | 2.0879 | 6.6986 | 66.3591 |
| G2-NY2DC-init | 同上 | 5 | test | 1.7360 | 5.6687 | 64.4227 |
| G2-CHI2DC-init | 芝加哥权重复制到学生后再蒸馏 | 17 | val | 2.0078 | 5.7935 | 83.1331 |
| G2-CHI2DC-init | 同上 | 17 | test | 1.7242 | 5.1286 | 82.2489 |

测试集对照（MAE / RMSE）：纽约初始化加蒸馏 1.7360 / 5.6687，介于随机初始化蒸馏（1.7519 / 5.5064）和纽约微调（1.7153 / 5.2786）的 MAE 之间，RMSE 高于两者。芝加哥初始化加蒸馏 1.7242 / 5.1286，MAE 低于随机初始化蒸馏（1.7485 / 5.4130），RMSE 也更低，但仍高于芝加哥微调（1.4773 / 5.0578）。
