# 实验结果（2026-10-28）

本机 RTX 4060 Laptop，`torch 2.11.0+cu128`，seed 42。指标是反归一化后有效格上的 MAE / RMSE，单位为每小时上车量。MAPE 因大量接近 0 的流量格被放大到千万量级，不参与比较。权重、日志和原始数据在本机，按 `.gitignore` 不入库。逐步记录见 [../notes/progress.md](../notes/progress.md)。

## 协议

- 输入为过去 6 小时，预测下一小时。验证集和测试集各 1440 小时。
- 源城教师（纽约、芝加哥）只在 5898 个训练窗口上训练。验证集用于早停，测试集只评估一次。这与 CrossTReS 把源城 train+val+test 拼进预训练不同。
- 华盛顿只用训练段最后 72 小时（3 天）。验证集和测试集仍各 1440 小时。
- 模型是带 BatchNorm 的 CrossTReS ST-Net。损失为有效格平方误差，先对 batch 取平均，再对格子求和。batch 8，学习率 0.001，权重衰减 5e-5，最多 50 个 epoch，验证 RMSE 连续 5 个 epoch 不升则停。
- Group 2 的教师直接吃华盛顿归一化窗口，不做区域匹配。蒸馏项与任务损失使用同一归约，λ = 1。学生随机初始化。
- G1-C 把源城权重复制到华盛顿后全部解冻，只有任务损失，没有蒸馏。

## 测试集

| 实验 | 设定 | 最佳 epoch | MAE | RMSE |
|---|---|---|---|---|
| G1-src-ny | 纽约教师，全训练段 | 15 | 4.32 | 15.55 |
| G1-src-chi | 芝加哥教师，全训练段 | 21 | 1.85 | 6.37 |
| G1-tgt-3d | 华盛顿从零训练，3 天 | 16 | 1.87 | 5.55 |
| G2-NY2DC | 冻结纽约教师，随机初始化学生 + 蒸馏 | 17 | 1.75 | 5.51 |
| G2-CHI2DC | 冻结芝加哥教师，随机初始化学生 + 蒸馏 | 12 | 1.75 | 5.41 |
| G1C-NY2DC | 纽约权重微调，无蒸馏 | 3 | 1.72 | 5.28 |
| G1C-CHI2DC | 芝加哥权重微调，无蒸馏 | 1 | 1.48 | 5.06 |

源城绝对误差不与华盛顿横比：纽约流量尺度上限 1212，芝加哥 536，华盛顿 234。

华盛顿三条设定的测试集对照：从零训练 1.87 / 5.55；蒸馏略低；复制源城权重再微调更低。芝加哥微调的 MAE 1.48、RMSE 5.06，是这一轮华盛顿上最低的一组。

## 微调加蒸馏（种子 42，λ = 1）

学生先复制源城教师权重（去掉源城 `spatial_mask`），教师另存一份并冻结，损失仍是 `L_task + 1.0 * L_kd`。协议与上面的华盛顿 3 天设定相同：batch 8，学习率 0.001，权重衰减 5e-5，早停 patience 5。MAPE 只在反归一化后真实流量大于 0 的格子上计算，分母就是该流量。RMSE 和 MAE 仍覆盖全部有效格。上表各行还没有用这个 MAPE 重算。

| 实验 | 设定 | 最佳 epoch | split | MAE | RMSE | MAPE |
|---|---|---|---|---|---|---|
| G2-NY2DC-init | 纽约权重复制到学生后再蒸馏 | 5 | val | 2.0879 | 6.6986 | 66.3591 |
| G2-NY2DC-init | 同上 | 5 | test | 1.7360 | 5.6687 | 64.4227 |
| G2-CHI2DC-init | 芝加哥权重复制到学生后再蒸馏 | 17 | val | 2.0078 | 5.7935 | 83.1331 |
| G2-CHI2DC-init | 同上 | 17 | test | 1.7242 | 5.1286 | 82.2489 |

测试集对照（MAE / RMSE）：纽约初始化加蒸馏 1.7360 / 5.6687，介于随机初始化蒸馏（1.7519 / 5.5064）和纽约微调（1.7153 / 5.2786）的 MAE 之间，RMSE 高于两者。芝加哥初始化加蒸馏 1.7242 / 5.1286，MAE 低于随机初始化蒸馏（1.7485 / 5.4130），RMSE 也更低，但仍高于芝加哥微调（1.4773 / 5.0578）。

## 种子 42 / 43 / 44（只重跑华盛顿）

种子 43 和 44 用 `--seed` 重跑了七类华盛顿设定，没有重训源城教师，也没有重跑种子 42 的训练。checkpoint 和结果 JSON 带 `_seed43` / `_seed44`，不覆盖种子 42 的文件。下表是测试集。种子 42 的 MAE / RMSE 来自原先的结果 JSON。那五次旧实验 JSON 里的 MAPE 仍是旧分母，这里的种子 42 MAPE 是用现有 checkpoint 按新定义重算的，没有重新训练。初始化加蒸馏的种子 42 MAPE 来自上一节的新训练。均值是三种子的算术平均。

| 设定 | 种子 42 MAE / RMSE / MAPE | 种子 43 | 种子 44 | 均值 |

| 纽约微调 | 1.7153 / 5.2786 / 72.3947 | 1.6344 / 5.1229 / 72.7873 | 1.6242 / 5.1752 / 73.4110 | 1.6580 / 5.1922 / 72.8643 |
| 芝加哥微调 | 1.4773 / 5.0578 / 73.3157 | 1.5319 / 5.0045 / 68.4041 | 1.5422 / 5.1079 / 74.8422 | 1.5171 / 5.0568 / 72.1873 |
| 纽约蒸馏，随机初始化 | 1.7519 / 5.5064 / 59.2878 | 2.0160 / 5.6691 / 76.2539 | 2.0585 / 5.8437 / 84.4423 | 1.9422 / 5.6730 / 73.3280 |

三种子均值里，芝加哥微调的测试 MAE 1.5171、RMSE 5.0568 仍然最低。纽约随机初始化蒸馏的 MAE 从种子 42 的 1.7519 升到种子 43 的 2.0160 和种子 44 的 2.0585，均值 1.9422，高于从零训练的均值 1.8850。
