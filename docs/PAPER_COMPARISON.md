# 相对直接训练的下降比例

日期：2026-11-16。数字只来自两处：本仓库已提交的 [RESULTS.md](RESULTS.md)、[profiles/cell_affine.md](profiles/cell_affine.md)、[profiles/shape_blend.md](profiles/shape_blend.md)、[profiles/grid_route.md](profiles/grid_route.md)，以及下面列出的论文公开 PDF。没有重跑官方代码，也没有把不同协议的绝对 MAE 排成一张榜。

相对变化一律写成

\[
r = \frac{E_{\text{direct}} - E_{\text{method}}}{E_{\text{direct}}}.
\]

\(E\) 是同一篇文档、同一种误差。\(r>0\) 表示该方法的误差低于直接训练，\(r<0\) 表示该方法更高。下表的百分数由印刷值按这个式子算出，保留两位。MAPE 的分母和 MAE 不同，单独列出，不拿来代替 MAE。

直接训练在本仓库里是华盛顿只用 3 天、从零训练的 ST-Net（G1-tgt-3d）。论文里各自的直接训练在每一节写明。

## 1. 我们自己的方法

协议见 [RESULTS.md](RESULTS.md)：出租车上车，过去 6 小时预测下一小时，华盛顿训练标签是下标 `[5832, 5904)` 的 72 小时，验证集和测试集各 1440 小时。MAE / RMSE 在反归一化后的有效格上计算。种子 42 的直接训练测试 MAE 是 **1.8701**，RMSE **5.5528**，MAPE **75.9919**。三种子均值是 MAE **1.8850**、RMSE **5.5234**、MAPE **76.8326**。

## 2. 论文里的方法，以及迁移有没有好于直接训练

下面只摘和「目标侧数据很少时，迁移或微调 vs 目标侧直接训练」有关的行。绝对 MAE 留在各文自己的列里。

### CrossTReS（Jin, Chen, Yang, KDD 2022）

方法：源城区域重加权的选择性迁移。预测骨干是 ST-Net，另外学习区域特征。实验还比较了普通微调和若干非选择性迁移。作者报告 5 次运行的均值。目标城华盛顿，源城纽约或芝加哥，目标训练量有 30 天、7 天、3 天。指标是上车和下车误差的平均。PDF：<https://www.cse.ust.hk/~kaichen/papers/CrossTReS-kdd22.pdf>，Table 1 的 DC Taxi。

和我们最接近的一列是 **3 天、DC Taxi**。该列里没有迁移的两个基线是 ARIMA 和 ST-Net。

| 方法 | 3 天 MAE | 相对该文 ST-Net 3.82 | 相对该文 ARIMA 1.81 |
|---|---:|---:|---:|
| ARIMA，无迁移 | 1.81 | — | 基准 |
| ST-Net，无迁移 | 3.82 | 基准 | −111.05% |
| 微调，纽约源 | 1.723 | +54.90% | +4.81% |
| 微调，芝加哥源 | 1.700 | +55.50% | +6.08% |
| CrossTReS，纽约源 | 1.577 | +58.72% | +12.87% |
| CrossTReS，芝加哥源 | 1.558 | +59.21% | +13.92% |
| CrossTReS-Mem，纽约源 | 1.542 | +59.63% | +14.81% |
| CrossTReS-Mem，芝加哥源 | 1.518 | +60.26% | +16.13% |

迁移和好于直接训练，这在该表里成立：微调和 CrossTReS 的 MAE 都低于无迁移 ST-Net，也低于 ARIMA。相对无迁移 ST-Net 的 55%–60% 不能单独拿来和我们的 8%–21% 比。该文 3 天 ST-Net 的 MAE 是 3.82，同一张表里的 ARIMA 是 1.81，深度模型在 3 天上比线性基线差一截；相对 ARIMA，CrossTReS 大约低 13%–14%，微调大约低 5%–6%。无迁移行印到两位小数，比例跟着这个精度。

该文还写源城用最后两个月做测试、再往前两个月做验证、其余约 8 个月训练。本仓库的源城教师只用训练段的 5898 个窗口，不把验证集和测试集拼回去。我们的指标是上车量，该文是上车与下车的平均。两套绝对 MAE 不放在一起排名。本仓库也没有实现它的区域重加权。

### STBaT（Hao et al., IJCAI 2025）

方法：在 ST-Net 骨干上加区域不平衡模块（RIAM）和时空平衡学习（STBLM）。源城预训练时不用目标城数据，再在目标城的 3 天或 0 天上适配。源城训练和验证按 2:1。目标城最后两个月测试、再往前两个月验证。骨干是 3 个残差块、64 通道、LSTM 隐层 128，输入过去 6 小时。误差同样是上车与下车的平均。PDF：<https://www.ijcai.org/proceedings/2025/0319.pdf>，Table 2 的 Taxi、Few-Shot。

华盛顿这一列，无迁移 ST-net 的 MAE 是 **1.851**。四个少样本任务的顺序是：华盛顿←纽约、华盛顿←芝加哥、芝加哥←纽约、纽约←芝加哥。这里只抄华盛顿。

| 方法 | 华盛顿 MAE | 相对该文 ST-net 1.851 |
|---|---:|---:|
| ST-net，3 天，无迁移 | 1.851 | 基准 |
| Finetuned，纽约源 | 1.794 | +3.08% |
| Finetuned，芝加哥源 | 1.675 | +9.51% |
| CrossTReS（该文重跑），纽约源 | 1.599 | +13.61% |
| CrossTReS（该文重跑），芝加哥源 | 1.561 | +15.67% |
| STBaT，纽约源 | 1.423 | +23.12% |
| STBaT，芝加哥源 | 1.413 | +23.66% |

表里的 Improvements +11.0% 和 +9.5% 是 STBaT 相对该列最好的其他迁移方法（这里是 CrossTReS 1.599 和 1.561），公式 \((1.599-1.423)/1.599\) 与 \((1.561-1.413)/1.561\)。它不是相对从零训练的比例。相对从零 ST-net，STBaT 大约低 23%，普通微调低 3%–10%。

该文的 3 天 ST-net MAE 1.851 和我们的 1.8701 数值接近，指标却是上车与下车的平均，源城划分也是 2:1。接近不等于同一口径。

### SFMGTL（Chen et al., arXiv:2302.11774）

方法：语义融合、多粒度图、公共记忆和目标城私有记忆；先源城与目标城一起预训练，再只在目标城微调。输入过去 6 步，预测下一步。源城用满 12 个月。目标城训练是 1 天、3 天或 7 天，验证和测试用最后 4 个月、各两个月。预处理写了 Min-Max。表 2 是 taxi demand，正文称为 taxi pickup/dropoff demand；每个设定只有一个 MAE，论文没有写成「上车误差与下车误差的平均」。HTML：<https://arxiv.org/html/2302.11774>，Table 2。

无迁移的 ST-Net 在两个方向的表里是同一行。3 天 MAE 是 **1.721**。

| 方向 | 方法 | 3 天 MAE | 相对该文 ST-Net 1.721 |
|---|---|---:|---:|
| 纽约 → 华盛顿 | ST-Net，无迁移 | 1.721 | 基准 |
| 纽约 → 华盛顿 | Fine-tuning | 1.520 | +11.68% |
| 纽约 → 华盛顿 | SFMGTL | 1.503 | +12.67% |
| 芝加哥 → 华盛顿 | ST-Net，无迁移 | 1.721 | 基准 |
| 芝加哥 → 华盛顿 | Fine-tuning | 1.714 | +0.41% |
| 芝加哥 → 华盛顿 | SFMGTL | 1.555 | +9.65% |

迁移好于该文的 3 天 ST-Net。纽约方向上，普通微调和 SFMGTL 的下降差不多（约 12%）。芝加哥方向上，普通微调几乎和从零 ST-Net 一样，SFMGTL 大约低 10%。同一篇论文里的 SFMGTL-Full 用目标城约 8 个月、不做迁移，MAE 1.229。那是数据充足时的另一条基线，不放进 3 天的比例。

### TransGTR（Jin et al., KDD 2023）

方法：在传感器速度图上联合学习可迁移的图结构和预测模型。节点特征网络用蒸馏对齐长期源数据和短期目标数据，预测模型是 Graph-WaveNet，结构生成用 GTS。目标训练 7 天或 3 天，预测未来 30 分钟和 60 分钟。城市是 METR-LA、PEMS-BAY → PEMSD7M、HKTD。这是速度，不是纽约/芝加哥/华盛顿的网格上车量。PDF：<https://www.cse.ust.hk/~kaichen/papers/transgtr-kdd23.pdf>，Table 1，5 次均值。

直接训练取该文的 Target Only GWN，因为 TransGTR 的预测器以 GWN 为底。下表只列 3 天。

| 目标 | 预测时长 | 直接训 GWN 的 MAE | TransGTR，源 METR-LA | 相对变化 | TransGTR，源 PEMS-BAY | 相对变化 |
|---|---|---:|---:|---:|---:|---:|
| PEMSD7M | 30 分钟 | 3.126 | 2.960 | +5.31% | 2.958 | +5.37% |
| PEMSD7M | 60 分钟 | 4.162 | 3.604 | +13.41% | 3.599 | +13.53% |
| HKTD | 30 分钟 | 3.477 | 3.305 | +4.95% | 3.290 | +5.38% |
| HKTD | 60 分钟 | 4.333 | 3.693 | +14.77% | 3.697 | +14.68% |

在这张表里，迁移低于目标城只用 3 天训练的 GWN。任务、城市和指标单位都与网格上车量不同，比例只说明「这篇论文报告迁移更好」，不与第 1 节的百分数比较。

### 同城压缩，单独搁置

ST-MLP（Zhang et al., IEEE TITS 2024）把同城的时空图网络蒸馏成 MLP，数据是传感器速度。IEEE 全文这次没有打开，这里不抄任何 MAE。它不回答跨城迁移是否好于目标城直接训练。

Izadi et al.（arXiv:2401.11798）也是同城压缩：教师和学生都在 PeMSD7 或 PeMSD8 上，学生大约保留教师 3% 的参数。HTML：<https://arxiv.org/html/2401.11798>，Table 4。PeMSD8、未来 15 分钟的 MAE：教师 1.211，不蒸馏的学生 1.472，他们的 \(L_{\text{STCD}}\) 学生 1.281。相对「小模型自己训练」，蒸馏低 12.98%；相对教师，学生仍高 5.78%。这是把大模型压小，不是把一座城的权重要到另一座城。

## 4. 可以怎么向导师说

跨城论文报告的结论是：在目标城只有大约 3 天数据时，迁移或微调的误差低于同一张表里的目标城直接训练。CrossTReS、STBaT、SFMGTL、TransGTR 都是这样。下降多少取决于直接训练是谁。CrossTReS 相对它自己那个 MAE 为 3.82 的 3 天 ST-Net 大约低 55%–60%，相对它表里的 ARIMA 大约低 13%–14%。STBaT 相对它自己的 3 天 ST-net 大约低 23%。SFMGTL 相对它自己的 3 天 ST-Net 大约低 10%–13%。

我们这边，微调好于华盛顿 3 天从零训：种子 42 上纽约低 8.28%、芝加哥低 21.00%；三种子均值是 12.04% 和 19.52%。这个数量级落在 STBaT、SFMGTL 相对它们自己的 3 天 ST-Net 的范围内，也高于 CrossTReS 相对 ARIMA 的范围。随机初始化蒸馏在三种子均值上没有稳定好于从零训，纽约均值还更高。后处理相对微调的再下降都很小。

这些百分数回答的是「各自相对自己的直接训练下降了多少」。它们不是对论文方法的复现，也不能把 1.87 和 3.82 或 1.72 放进同一个排序。
