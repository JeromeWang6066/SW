## 主要内容

三件事。

1. **现在这套可以先写成一段完整方法。** 过 150 门的那 50 格已经比较准，剩下的 MAE 主要在其他格上。那些格数据量小。不要只靠 ≥150 这一刀：140 和 150 可能是同一类。再加一步筛选，用时空相关看 heatmap，例如大于 0.5 或大于 0.8 才做。非线性、不可重复的模式不必全做。
2. **现在不是在线学习，前半仍是开环。** 每个钟点用前几天同一个小时做最小二乘，当天只做 inference，不改训练。可以叫用到了当时的数据，但不是滑动的在线更新。若要闭环：每小时做一次 recursive least squares，或加 Kalman filter 这类跟踪；跟踪和原来的历史预测差过阈值，就认为当天有临时特征，用跟踪结果做实时修正。也可以用最近四个点预测下一个点。闭环要回答的是：一天结束返回什么数，这个数怎样加回循环。
3. **周一前把现有方法写成一篇完整草稿。** 导师有 invited paper 的位置，可以单独送审，但仍要审稿，不是直接塞进去。学生自己写，related work 也自己写。不许抄，不许让模型生成正文。写完后用它查语法可以。相似度过高是严肃问题。Overleaf 链接导师建好后发。六号有会，不能再晚。

## 1. 现有方法和 150 这一刀

导师认为眼下的结果可以先站住。后续做什么可以再想。当前做法先当成一个完整方法，用正式写法写下来。

学生的判断：单看过门的 50 格，MAE 已经很小。全图 MAE 主要来自其余格子。那些格也想做校正，但数据量小。

导师的意见：≥150 是 hard cutoff，一定会一刀切。合计 140 的格子有可能和刚过 150 的格子是同一类，不能只因为差在门槛一侧就丢掉。在这一刀之外再筛一次。用 spatiotemporal correlation 看哪些格子还值得做，例如 heatmap 上大于 0.5，或大于 0.8。不必每格都做。有些 nonlinear pattern 不可重复，相关比较就是用来把这些筛掉。

听写是 “Sparkle comparison”。结合前面的 nonlinear，更像 Spearman。仓库里已经在用的相关是 Pearson。这次没有说把 Pearson 换成 Spearman，也没有给新的阈值表。0.5 和 0.8 的说法与 [2026-11-05-meeting.md](2026-11-05-meeting.md) 里的举例相同，仍是举例。

## 2. 现在是离线的按小时拟合

导师问现在的 “在线” 到底是什么：在线滑窗，还是别的。他的判断是，这里仍是 offline，只是用到了这段数据，并不是真正的 online，也还牵着一个滑动窗口的问题。

学生确认：确实是 offline。只用当天这段数据做了一次拟合，不影响 training。

导师补充：用到了当时的数据，说 online 也说得通，但含义要讲清楚。原来的预测是更大尺度上的周期规律，现在每个小时这一步是动态调整。上次已经说过，至少要有 feedback 回来，变成闭环，闭环更容易到稳态。

学生提到闭环只有一部分。导师指当前写法的前半（听写像第 4、5、6 节）仍是开环。如果还想用 online learning 这个词，要把时间关系写明白。

导师先以为是每个小时做一次最小二乘，用来修下一个小时。学生更正：不是。每个钟点用前面几天同一个钟点的数据做最小二乘，再预测今天这个钟点，例如前几天的早上八点。每个小时都用到前面三天。

导师接受这个说明。这是 curve fitting。那一天上的预测是拟合之后拿来用的，这一天本身只做 inference，不是在线更新。

## 3. 若要做成闭环

导师建议把它改成在线，三选一的方向，会上没有指定先做哪一个。

- 把现在的最小二乘改成 recursive least squares：每过一个小时做一次拟合，用低秩更新并进已有数据。最小二乘可以直接算。听写是 “RSR” 和 “低质 update”。低质与低秩同音，recursive least squares 的更新就是秩一修正；听成「递推更新」也可以。不在这里新写一套更新公式。
- 或者加一个 tracking，例如 Kalman filter，跟上曲线变化，把变化看成趋势。前头的预测仍 purely 来自 historical data。每过一个小时把跟踪结果和原来的预测比。偏差超过一个 threshold，就认为当天有以前没出现过的临时特征，用跟踪结果替代原来的预测，或再加修正项，变成实时修正。听写 “carbon future” 按 Kalman filter 理解；“stressful” 按 threshold 理解。听写里的 “PID prediction” 可能是原来的 period / prior / baseline prediction，也可能就是 PID。会上没有选定控制器，不把它写成方法的一部分。
- 或者做超短期 projection：用前面四个点预测下一个点。听写 “运行一个点” 按「预测一个点」理解。

现在的做法是用过去的数据做一次偏差修正。导师说成「昨天」，学生说的是前几天同一个小时。整理时以学生更正后的「前三天、同一钟点」为准。听写 “再加一个很恐怖” 对不上，不另加模块。

学生问闭环一般用什么做。导师的定义：feedback loop 要能 return 一个值。一天结束能返回什么，这个值怎样加回循环。学生觉得现在每天都是离线拟合，没有东西可反馈。导师重申：现在只是画了一条线，是 offline training，也就是一个线性的 projection，线性 extrapolation。听写 “explanation” 按 extrapolation 理解。最简单的在线做法仍是上面的 recursive least squares，每小时拟合一次，加进原有数据。

学生表示回去再看。会上没有定阈值数字，也没有定先做 RLS、Kalman，还是四点外推。
