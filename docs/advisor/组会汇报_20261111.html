方法在 72 小时上拟合 p′ = a·p + b（λ = 72，把 a 拉向 1、b 拉向 0）；低流量的 157 格保持 a = 1、b = 0。同一组系数用到验证与测试的每一个小时。

下一步工作：仿射校正的多种子复核

复核设计

种子43、44。λ 仍是 72，流量门槛仍是三天上车合计 ≥ 150。
判定每个种子先看验证集全市 MAE，必须严格低于该种子的一律微调，才看测试集。
报告看测试集时必须分开写出高流量 50 格与低流量 157 格。
对照该种子自己的芝加哥整城微调，不是种子 42 的 1.4773。
不动0.5、0.8、150 与 λ 都不按这张新表调整。

优先级依据

  • 后续分组实验要把「微调 + a、b」当作对照，对照本身必须先站住
  • 此前周末/节假日分训正是在多种子上方向不一致才被放弃，教训是单种子结果不足为凭
  • 三种子同向下降，才谈得上把 a、b 写进方法

后续方案：基于日周期形状的分组迁移

实验设计

  • 源城里按工作日 24 小时形状把上车多的格子聚成约 8 组，同组共用一个小模型；输入含该格自身近几小时与邻域合计，用长历史训练
  • 迁到华盛顿时，用该格这三天的形状去选组，不匹配单个源格；组模型只修正形状，再与整城微调合成
  • 水平仍用第 6 页的 a、b 在 72 小时上拟合，只在三天上车合计 ≥ 150 的格子上做
  • 卷积与 LSTM 结构不动，不逐格重训

判定标准

对照芝加哥整城微调 + a、b。
停止验证集全市 MAE 不更低就停，不看测试集。
