问题定义02

网格不对齐下的少样本跨城预测

源城（纽约 / 芝加哥）数据充足，目标城（华盛顿）仅有 3 天训练数据；两城网格无法逐格对应，区域编号不能直接互拷。

任务设定

输入 / 输出过去 6 小时网格出租车上车量，预测下一小时。
源城教师纽约或芝加哥上训练 ST-Net，训练后冻结。
目标城华盛顿，STBaT 式 3 天 few-shot（72 小时）。
核心问题在区域不对齐的前提下，跨城知识迁移能否稳定优于目标城从零训练。
阶段范围第一阶段仅预测出租车上车量；下车量、单车通道未纳入。
研究假设：以工作日 24 小时轮廓相关 ρ̃ 调制蒸馏项，可降低不相似区域带来的负迁移。该假设本次尚未检验。

实验设置06

模型、损失与训练

骨干为 CrossTReS ST-Net，第一阶段不更换网络；蒸馏发生在预测输出上。

模型与优化

骨干ST-Net：3 个 64 通道残差块 + LSTM 128，含 BatchNorm。
任务损失有效格平方误差；batch 上取平均，格子上求和。
优化batch 8，学习率 1e-3，权重衰减 5e-5。
早停最多 50 epoch，验证 RMSE 连续 5 epoch 不升则停。

蒸馏损失​

形式L = Ltask + λ · Lkd，主实验 λ = 1。
Lkd预测输出上的 MSE；教师冻结，直接读取华盛顿归一化窗口。
归约与任务损失一致：batch 平均、格子求和。
缺失无区域配对、无 ρ̃ 乘子、无隐藏表示蒸馏。
G1-C 为复制源城权重后全参数微调，只有任务损失，作为迁移下限对照。

观察

  • 教师初始化 + λ = 0.1 为扫描中最低：MAE 1.478、RMSE 4.933
  • 该点 MAE 与纯微调（1.477 / 5.058）几乎相同，RMSE 更低
  • 随机初始化在 λ = 1 最好；λ = 5 明显变差，蒸馏项过强有害
  • 教师初始化组对 λ 更敏感：0.1 → 1 单调变差

解读边界

  • 仅种子 42，λ = 0.1 的优势需多种子复核 [待补充]
  • 纽约方向的 λ 扫描未做 [待补充]
  • 不能据此断言蒸馏优于微调；更合理的解释是小 λ 蒸馏接近正则
目前证据支持的表述：权重复制 + 微调是最稳的迁移手段；小权重蒸馏项可能有辅助作用，但证据尚不充分。

讨论10

结果解读与研究意义

现有结果

  • 3 天少样本下，跨城迁移（至少权重复制）显著优于从零训练
  • 迁移收益主要来自初始化本身，而非当前形式的蒸馏项
  • 蒸馏权重过大（λ = 5）带来负收益，说明蒸馏项需要调制
  • 评估管线、指标口径、复现脚本已可重复运行

对研究命题的意义

  • 标准蒸馏的不稳定性（NY 方向均值劣于基线）恰好印证了负迁移的存在
  • 这为 ρ̃ 乘子提供了动机：不加区分地蒸馏可能损害目标城
  • 微调基线（CHI 微调 1.517 / 5.057）成为 Group 3 / 4 必须超越的参照
  • 乘子方法应与「同配对、乘子恒 1」公平对比，而非只比从零训练
研究价值在于把「是否迁移」推进到「如何有选择地迁移」
