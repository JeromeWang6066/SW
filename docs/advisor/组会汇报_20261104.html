模型、损失与训练设置

Phase-1 不换骨干；所有对照共用同一模型与早停规则。

模型与优化

骨干带 BatchNorm 的 CrossTReS ST-Net；3 个 64 通道残差块、LSTM 隐层 128；输出 (B, 1, N_valid)。
任务损失有效格平方误差，先对 batch 取平均，再对格子求和。
优化batch 8、lr 0.001、weight decay 5e-5、最多 50 epoch；验证 RMSE 连续 5 个 epoch 不下降即停。
指标MAE / RMSE 覆盖全部有效格；MAPE 只在真实流量大于 0 的格子上计算，分母为该流量。

现有蒸馏形式

L = Ltask + λ · Lkd
教师冻结并保持 eval；读取华盛顿归一化窗口，不是「按小时缓存源城隐藏表示」。
蒸馏项学生与教师预测输出的 MSE，与任务损失同一归约；乘子恒为 1，无区域配对。
开关λ 主实验取 1，扫描取 0.1 / 0.5 / 5；pearson_multiplier 全为 false，置 true 时训练入口直接拒绝。

该损失不是选题第 12 页的「乘子 × 隐藏表示距离」，两者不共用同一组结果。种子 42 主实验的 MAPE 由已有 checkpoint 重算，未重训。

结果解读与研究意义

四条结论只覆盖「输出 MSE 蒸馏、无区域配对」这一阶段。

01基线可用四套设定共用同一划分、同一 ST-Net 与早停，后续方法可直接接入同一对照组。
02初始化与蒸馏增益可分开微调在三个种子上稳定优于从零；随机初始化蒸馏在纽约方向均值 1.942，高于从零的 1.885。
03λ 的量级已测教师初始化下 λ 由 0.1 增至 5，MAE 由 1.48 升至 1.94；引入乘子时应把 λ 作为受控变量。
04边界清楚现有蒸馏作用于预测输出；选题要检验的是按 ρ̃ 加权的隐藏表示距离，二者不是同一损失。
以权重微调为基线，先确定跨城格子配对，再讨论乘子；本阶段的负结果是 Group 3 的对照依据。

不写入本次汇报：CrossTReS 原文「约降低 8%」、旧日志千万量级 MAPE、Group 3 / 4 数值 [待补充：未执行]。
