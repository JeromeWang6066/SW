## 已复核的对照结论（仅此锁定评价）

- 调新（NEW_VAL）在全部六个任务上 test MAE 均优于调平移（SHIFT_VAL），支持**本次**斜率项相对只平移有额外作用；不是普遍保证。

- 新固定 κ=1（NEW_FIXED）在 6/6 任务上 test MAE 不及旧固定 λ=72（OLD_FIXED）。

- 调新相对调旧（OLD_VAL）：仅 NY44 test MAE 更好，其余 5/6 更差。

- val 选参相对各方法默认强度的 test MAE：调旧 4 差 2 同（NY42/NY43 因选中默认 m=1 而相同；其余更差），调新 3 差 3 同（NY43/NY44/CHI42 选中默认 κ=1；其余更差）。本次没有出现 val 选参优于该法默认的 test 任务。
