## 判定

- 一次判定，总量：验证集没有留下。至少有一个源城的工作日 MAE 高于 50 格全放行。
- 一次判定，小时相对误差：验证集没有留下。至少有一个源城的工作日 MAE 高于 50 格全放行。
- 一次判定，钟点轮廓：验证集没有留下。至少有一个源城的工作日 MAE 高于 50 格全放行。
- 一次判定，留出日有用，τ=0.0：无法区分。ny -0.0131 [-0.0160, -0.0102]；chi -0.0051 [-0.0073, -0.0027]。方向不稳定。
- 按日判定，总量：验证集没有留下。至少有一个源城的工作日 MAE 高于 50 格全放行。
- 按日判定，小时相对误差：验证集没有留下。至少有一个源城的工作日 MAE 高于 50 格全放行。
- 按日判定，钟点轮廓：验证集没有留下。至少有一个源城的工作日 MAE 高于 50 格全放行。
- 按日判定，留出日有用：验证集没有留下。至少有一个源城的工作日 MAE 高于 50 格全放行。

## 局限

阈值网格是事先写定的五个点，不是连续搜索。种子 43、44 只检验选定的 τ，不另选。
测试段在钟点偏差的实验里已经看过。这次仍是探索性对照。
一次判定的周末沿用三个工作日上算出的那道门。按日判定的周末用周末自己的窗口。
