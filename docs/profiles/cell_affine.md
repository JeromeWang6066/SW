# 按格水平和位移

通道是出租上车。种子 42。没有新训练。
起点是已经训好的整城微调。每个过门格子在三天窗口上拟合 `p' = a * p + b`。
岭回归的 λ 是 72，把 `a` 拉向 1、把 `b` 拉向 0。
三天原始上车合计少于 150 的格子固定 `a = 1`、`b = 0`。
λ 和 150 都在看验证集、测试集之前定下，之后没有改。
校正用的预测和标签是反归一化后的上车量。门槛用原始计数。

有效格 207 个，过门 50 个。
未校正的验证集和测试集 MAE、RMSE 与已发表的微调结果相差不超过 0.001，才写这张表。
