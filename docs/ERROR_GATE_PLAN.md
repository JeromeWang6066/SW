# 150 门前面的误差判断

日期：2026-11-24。本页在打分之前写定。它只回答一个问题：在已经过了 150 门的格子里，再加一道误差判断，会不会比「50 格全部校正」更好。

150 门不改。没过 150 门的格子保持微调。误差判断不通过的格子也保持微调，和微调逐位相同。不重训，不改 λ=72，不改 κ=3，不搜索新的窗口长度。阈值网格写在下面，验证集只在这个网格里选，测试集不参与选择。

校正公式与 [CLOCK_HOUR_LOOP_PLAN.md](CLOCK_HOUR_LOOP_PLAN.md) 相同：`solve_old(..., 1)` 加 `hour_offsets(..., kappa=3)`。本实验只决定哪些过门格使用这组系数。

## 1. 两种用法

| 模式 | 误差在哪段上算 | 系数从哪段来 | τ=全部放行时等于 |
|---|---|---|---|
| 一次判定 | 2016-08-31 至 09-02，只算一次 | 同一段，之后不再重估 | OL，已发表的训练窗钟点偏差 |
| 按日判定 | 目标日之前最近三个同类日 | 同一段，每个同类日 0 点重估 | CL，同类日滚动 |

一次判定对应会上的流程图：进入拟合之前看一次实际值。按日判定把这道门也放进闭环，成员可以在后来的日子进入或退出。两种模式分开选阈值，也不把 CL 和 OL 比出的差距算到门上。

工作日是周一到周五。2016-09-05 仍算工作日。

## 2. 四种距离

都在选定的 72 小时上、按格计算。分母用实际上车量。分母为 0 时距离记 0，这一格不放行。放行条件是距离严格大于 τ。

### 总量

\[
g=\frac{\bigl|\sum_t(y_t-p_t)\bigr|}{\sum_t y_t}.
\]

这是「大约 100 对大约 80」那种三天总量差。小时上的正负会抵消。

网格：0、0.05、0.10、0.15、0.20。

### 小时相对误差

\[
g=\frac{\sum_t|y_t-p_t|}{\sum_t y_t}.
\]

每个小时都算数。训练窗上它和 72 小时上车量几乎是倒序，这里仍按写定的网格做对照。

网格：0、0.25、0.35、0.45、0.55。

### 钟点轮廓

把窗口折成 24 个钟点，先对窗口里的天数取平均，再比较两条轮廓：

\[
g=\frac{\sum_{h=0}^{23}|\bar y_h-\bar p_h|}{\sum_{h=0}^{23}\bar y_h}.
\]

网格：0、0.15、0.25、0.35、0.45。

### 留出日有用

三天里每次留出一天。另外 48 小时上用同一套公式拟合 \(a,b,s_h\)，看留出那 24 小时的 MAE 是否低于微调。三天的相对降幅取平均：

\[
g=\mathrm{mean}_{d}\frac{\mathrm{MAE}^{\mathrm{微调}}_d-\mathrm{MAE}^{\mathrm{校正}}_d}{\mathrm{MAE}^{\mathrm{微调}}_d}.
\]

微调 MAE 为 0 的那一天，这一项记 0。这里的拟合只用来开门，真正用到目标日上的系数仍是第 1 节那一段完整 72 小时，不是留出日的系数。

网格：0、0.01、0.02、0.05、0.10。τ=0 表示只放行留出日上平均更低的格子，不等于 50 格全放行。

## 3. 选择

只在种子 42、纽约和芝加哥上选择。指标是验证集周一到周五的全市 MAE，口径与 `score_arrays` 相同。

对每种模式、每种距离：

1. 只保留两个源城的验证集工作日 MAE 都不高于「50 格全放行」的 τ。容差 \(10^{-12}\)。
2. 在这些 τ 里取两城平均 MAE 最低的。并列时取较小的 τ。
3. 若最好的一个和全放行在两城上都相同，或者没有任何 τ 被保留，就不新开门，结果写「沿用全部 50 格」。

种子 43、44 不参与选择。种子 45、46 这次不跑。

## 4. 测试

验证集结果写入 `docs/profiles/error_gate_val.json` 之后才打开测试缓存。测试只评估第 3 节留下的门，以及两条全放行基线。不再改 τ。

主比较是种子 42，两个源城，工作日测试 MAE。差是「这道门减同一模式的全放行」。区间是 43 个工作日的块自助，2000 次，生成器种子 0。

- **更好**：这道门在验证集被留下，两个源城的 97.5% 分位都小于 0，并且工作日 RMSE 都不高于全放行。
- **更差**：任一源城的 2.5% 分位大于 0。
- 其余，或验证集没有留下这道门：不把测试集上的高低写成这道门的胜负。验证集没留下的，测试段只写「未采用」。

稳定性：种子 42、43、44 共六个任务，工作日 MAE 差符号相同且不为 0，才写「方向稳定」。稳定性不改主比较。

周末 MAE 照实写，不参与选择，也不参与主比较。

## 5. 必须先通过的核对

1. 一次判定、50 格全放行，种子 42 的验证集和测试集工作日 MAE 与 `clock_hour_loop` 里的 OL 相差不超过 \(10^{-8}\)。
2. 按日判定、50 格全放行，同样对上 CL。
3. 157 格与微调的最大绝对差是 0。
4. 改目标日的 \(y\) 不改变这一天的距离。距离只用目标日之前的窗口。这一条由单元测试覆盖。

任何一条不过就停止，不解释后面的 MAE。
