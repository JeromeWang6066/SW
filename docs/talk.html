系统结构

源城训练，华盛顿三天微调，再用一个 κ 按格子收一收预测

这一格上在解什么

只对三天上车合计不少于 150 的格子。p 是微调预测，y 是真实上车，单位都是每小时上车量。主比较把 κ 定成 1。

量的含义

p̄　这 n 个小时预测的平均值。最终拟合时 n = 72，留一天时 n = 48。

pc,t = pt − p̄　把预测减去自己的均值，只留下这一小时比平均偏高还是偏低。

rt = yt − pt　微调还没补上的差。正数表示真实上车比预测多。

S = Σ pc,t²　起伏的总能量。S 越大，形状越容易被这几天的数据定住。

CV² = Sn p̄²　起伏相对于平均水平有多明显。CV² 小，说明这格的预测几乎是一条平线。

J(ã, c) = Σ (rt − ã pc,t − c)² + κ n p̄² ã² + κ n c²
第一项让校正去补上残差。后两项把 ã 和 c 往 0 拉，也就是别离「原预测不动」太远。κ n p̄² 把形状那一项换成上车量的尺度，才能和 c 放在一起罚。
因为 Σ pc,t = 0，形状项和水平项互不牵扯，可以分开解。
ã = Σ pc rS + κ n p̄² = ãOLS · CV²CV² + κ
ãOLS 是完全不惩罚时，用起伏去解释残差得到的倍率。后面那个分数是收缩：CV² 比 κ 大，就多留一点这个倍率；CV² 很小，ã 就被压回 0。κ = 1 且 CV² 也接近 1 时，大约留下一半。
c = Σ rn (1 + κ) = r̄1 + κ
r̄ 是这 n 小时残差的平均，也就是预测整段偏低或偏高多少。c 只取其中的 11 + κ。κ = 1 时，整体只补上平均缺口的一半。
p′t = pt + ã pc,t + c
ã 只改高低起伏，c 只改整段水平。一座城、一次微调共用一个 κ；它在这三天里留一天轮流试，验证集和测试集不参加选择。

微调、旧式子和 κ = 1

测试集全城 MAE，单位是每小时上车量。

实验内容（PR #20，无新训练）
  • 起点是种子 42 / 43 / 44 已经训好的整城微调。门槛不变：72 小时原始上车合计不少于 150 的 50 个格子做校正，其余 157 格保持原预测。
  • 旧式子 p′ = a·p + b（λ = 72，PR #18 的按格仿射）；新式子换成中心化形式 p′ = p + ã(p − p̄) + c，形状项和水平项分开惩罚，主设定 κ = 1。
  • 强度候选是 0、0.125、0.25、0.5、1、2、4、8、16、∞。只在训练的三天里留一天轮流选（8 月 31 日、9 月 1 日、9 月 2 日，平局取更大的强度）；验证集和测试集不参加选择。

直接结论
  • 主比较（测试 MAE，旧式子 λ = 72 减新式子 κ = 1）：种子 42 纽约 +0.0024 [0.0003, 0.0045]，芝加哥 +0.0080 [0.0023, 0.0133] —— 新式子在两城都更低；六个「源城 × 种子」的差值符号全部相同，方向稳定。
  • 两种校正都好于不校正的微调；三种子平均同样是两种校正更低，且新式子 κ = 1 又略优于旧式子 λ = 72。
  • κ = 0（不惩罚）明显更差：种子 42 纽约 1.7292、芝加哥 1.4873。惩罚项是校正收益的主要来源。
  • 留一天选出的 κ 取到 0.5 / 1 / 2（六个「源城 × 种子」依次是 1、1、2、0.5、1、0.5）；旧式子的倍数有时选到 ∞，等于不校正。
