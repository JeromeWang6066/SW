# 按格校正的下一组方法：小时偏差、L1 仿射、中位数截距、残差门

日期：2026-11-23。本页在打分之前写定。不重训，不改 150 门，不在验证集或测试集上选参数。输入仍是已经核对过的 `cell_affine_v2` 预测缓存。

上一组实验里，非负裁剪的测试 MAE 下降不到 0.001；纯乘法和事先固定的 L1/Huber 缩放没有超过旧公式 λ=72。所以这组不再改「只有一个斜率、没有截距」的形式，改去动三件还没试过的事：偏差随钟点变化、平方损失和 MAE 不一致、以及本来就没偏的格子不该被校正。

测试小时以前已经被看过。结果是探索性对照。

## 2. 方法

拟合只用 72 个训练小时。数组第 0 行是午夜，钟点是行号对 24 取余。验证集和测试集的窗口也从午夜对齐，套用时用同一个余数。没过 150 门的格子保持原预测。

### 2.1 按钟点收缩的加性偏差（HOD）

每个过门格、每个钟点 h 有 3 个残差。κ=3，事先固定：

\[
s_h=\frac{\sum_{i=1}^{3} r_{h,i}}{3+3}=\frac12\bar r_h,\qquad p'_t=p_t+s_{t\bmod 24}.
\]

不另设斜率。κ 不搜索。

### 2.2 旧公式之后再加钟点偏差（O72H）

先用已发表的 λ=72 解出 \(a,b\)。再对残差 \(y_t-ap_t-b\) 做上面的钟点收缩，κ 仍是 3。

\[
p'_t=ap_t+b+s_{t\bmod 24}.
\]

### 2.3 用 L1 重拟合原来的直线（LAD）

目标仍是把 \(a\) 拉向 1、把 \(b\) 拉向 0，λ=72，但数据项改成绝对误差。用迭代加权最小二乘，最多 40 步，权重 \(1/\max(|e|,10^{-3})\)，从旧公式的解出发：

\[
\sum_t w_t(y_t-ap_t-b)^2+\lambda(a-1)^2+\lambda b^2.
\]

这和上一轮「纯乘法 + \(\kappa\sum|p|\,|\tilde a|\)」不是同一个惩罚。上一轮那个惩罚把 \(a\) 全部拉回了 1。

### 2.4 斜率沿用旧公式，截距改成中位数（MED）

\(a\) 用 λ=72 的解。给定这个 \(a\)，令 \(b=\operatorname{median}(y_t-ap_t)\)。这一步直接对齐绝对误差的截距，不再惩罚 \(b\)。

### 2.5 只校正平均残差大于 0.5 的格子（GATE）

0.5 次上车事先固定，不搜索。过了 150 门、并且 72 小时平均残差 \(\bar r>0.5\) 的格子，用旧公式的 \((a,b)\)。其余格子保持原预测。

## 3. 判定

主对照是旧公式 λ=72。每个新臂单独判。六个任务的测试 MAE 都更低，并且种子 42 上两个源城的按天块自助 97.5% 分位都小于 0，才写「超过旧公式」。自助 2000 次，生成器种子 0。差是该臂减旧公式。

MAPE 不参与判定。不从这五条里按测试集再挑一条当成主结果。
