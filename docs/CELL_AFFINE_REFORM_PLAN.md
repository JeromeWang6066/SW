# 按格校正的三项改动：非负裁剪、纯乘法、对齐 MAE 的损失

日期：2026-11-23。本页在打分之前写定。它不改 `scripts/17_cell_affine.py`、`scripts/19_cell_affine_v2.py`，也不改已经发表的 λ=72 和 κ=1 数字。新结果只写在 `docs/profiles/cell_affine_reform.md`。

对照问题来自已入库实验，不是新的假设扫描：

- 旧公式 λ=72 的测试 MAE 低于中心化公式 κ=1，但中心化公式的测试 RMSE 更低。
- 中心化公式把水平修正推到截距上之后，测试段负预测明显变多。
- 拟合用的是平方误差，主指标是 MAE。κ=0 已经比 κ=1 差，继续在验证集上选 κ、或把 κ 拆成两个，没有在测试集上超过固定强度。

本轮只做三件事先说定的事。误差反馈门控不在本轮。

## 0. 不做什么

- 不重训 ST-Net，不读新的权重。输入是 PR #20 已经核对过的反归一化预测缓存。
- 不在验证集或测试集上选择 κ、δ 或任何门槛。
- 不改 150 的上车量门，不改「没过门则 a=1、b=0」。
- 不把测试集当盲测。这些测试小时在以前的实验里已经被看过。本轮是探索性对照，不写成部署结论。
- 不裁剪已经发表的表。裁剪只作为新臂，和未裁剪的同一对系数并排。

## 2. 三个改动，九个臂

拟合只用 72 个训练小时。验证和测试只套用已经冻结的系数。没过门的格子在所有臂里都是 a=1、b=0。κ 一律固定为 1，除了专门用来看「去掉惩罚」的 M0。

### 2.1 非负裁剪（不重新拟合）

\[
p'_t=\max(0,\ a p_t+b).
\]

系数与未裁剪臂相同。真实上车量非负，所以只要出现负预测，裁剪后的 MAE 和 RMSE 不会变差。这一臂回答的是：已经解出来的系数，负预测拖了多少 MAE。

### 2.2 纯乘法，去掉平移 c

\[
J_M(\tilde a)=\sum_t(r_t-\tilde a\,p_t)^2+\kappa\Big(\sum_t p_t^2\Big)\tilde a^2,
\qquad
\tilde a=\frac{\sum_t p_t r_t}{(1+\kappa)\sum_t p_t^2},\quad a=1+\tilde a,\quad b=0.
\]

\(r_t=y_t-p_t\)。\(\sum p_t^2=0\) 时返回 (1, 0)。κ=∞ 也返回 (1, 0)。b 固定为 0，所以 \(p_t=0\) 时校正后仍是 0。κ=0 时 \(a=(\sum p_t y_t)/(\sum p_t^2)\)。

### 2.3 对齐 MAE 的两种损失，仍是纯乘法

L1，κ=1：

\[
J_L(\tilde a)=\sum_t|r_t-\tilde a\,p_t|+\kappa\Big(\sum_t|p_t|\Big)|\tilde a|.
\]

一维凸函数，用黄金分割在能包住下降方向的区间上求最小，80 次。平的区间里取中点，不另挑。

Huber，δ=5 次上车，κ=1，事先固定，不搜索：

\[
\rho_\delta(e)=\begin{cases}e^2/2,&|e|\le\delta,\\ \delta(|e|-\delta/2),&|e|>\delta,\end{cases}
\qquad
J_H(\tilde a)=\sum_t\rho_\delta(r_t-\tilde a\,p_t)+\frac\kappa2\Big(\sum_t p_t^2\Big)\tilde a^2.
\]

从纯乘法的 κ=1 解出发，牛顿法最多 50 步，步长小于 1e-12 停止。δ=5 是「大约一次上车的几辆」这个量级，不是从验证集读出来的。

## 3. 指标和判定

每个臂、每个源城、每个种子、train/val/test 都报全城 MAE、RMSE、MAPE，以及测试段负预测个数。MAPE 不参与判定。RMSE 用缓存里的 `value_scale`，口径与 `score_arrays` 相同。

测试 MAE 相对 O72 的差，用按天的块自助，2000 次，`numpy` 生成器种子 0。差是该臂减 O72，负值表示该臂更低。

**裁剪是否有用**（O72C 对 O72，N1C 对 N1，分开判）：两个源城、三个种子的测试 MAE 都更低，并且种子 42 上两个源城的自助 97.5% 分位都小于 0。否则写「裁剪没有在预注册规则下单独成立」。差为 0 算没有更低。

**新公式是否超过旧公式**（M1、L1、H5 各自对 O72）：六个任务的测试 MAE 都更低，并且种子 42 上两个源城的自助 97.5% 分位都小于 0。少一条就不写「更好」。M0 只列表。

不允许的说法：用测试表挑一个臂再当成主结果；把万分之几的 MAE 写成迁移成败；声称测试集仍是未见数据。
