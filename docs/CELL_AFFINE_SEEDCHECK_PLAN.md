# 两粒新种子上的工作日核对

日期：2026-11-23。本页在新种子打分之前写定。不改网络结构，不改 150 门，不改 λ=72，不改 κ=3。不在验证集或测试集上重选参数。周末不进入这次判定。

上一份稳健性检查里，钟点偏差在工作日上六个旧任务都更低，在周末上六个都更高。训练窗 2016-08-31 到 09-02 本身就是三个工作日。这次只问：换成没看过的种子之后，工作日测试段是否还更低。

## 1. 新种子

种子 45 和 46。源城仍是纽约和芝加哥，各训一次华盛顿三天微调，配置仍是 `configs/finetune_ny2dc.yaml` 和 `configs/finetune_chi2dc.yaml`。已有的 42、43、44 不重训，也不加入这次判定。

四个任务：纽约 45、纽约 46、芝加哥 45、芝加哥 46。

## 2. 校正

和已经报告的方法相同。过门格用全部 72 个训练小时解 λ=72 的 \(a,b\)，再对残差做 κ=3 的钟点收缩。没过门的格子保持微调原预测。过门掩码必须和种子 42 那张 50 格掩码相同。

## 3. 判定

测试从 2016-11-02 00:00 起。只保留周一到周五的小时，周六周日整段不计入。

四个任务的工作日测试 MAE 都严格低于旧公式 λ=72，才写「新种子的工作日上也更低」。差是本方法减旧公式。按工作日做 2000 次按天自助，生成器种子 0，只报告区间，不作为通过条件。

微调原预测的全市测试 MAE 必须和该种子训练日志里的测试 MAE 相差不超过 1e-3，否则停止，上面的通过与否不采用。
